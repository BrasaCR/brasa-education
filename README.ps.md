# BRASA زده کړه

**هر ښوونځی، هره کچه، هر زده کوونکی—هېواد پر هېواد سره نښلول شوي.**

[BRASA زده کړه پرانیزئ](https://brasa.education/) · [BRASA نړۍ](https://brasa.world/) · [حکومت](https://brasagovernment.net/) · [سوداګري](https://brasa.business/)

BRASA زده کړه له وګړو سره د ښوونځیو، پوهنتونونو، کورسونو، سندونو او وړیا زده‌کړیزو سرچینو په موندلو کې مرسته کوي. هر هېواد خپله تعلیمي پاڼه او د ښوونځیو لړلیک ترلاسه کوي چې د هماغه هېواد له اصلي BRASA پاڼې سره تړلی وي.

## وګړي څه موندلی شي

- دولتي او خصوصي ښوونځي چې تایید شوي معلومات یې شته
- پوهنتونونه او تخنیکي زده کړه
- وړیا کورسونه او سندونه
- د ماشومانو او لویانو لپاره د زده کړې لارې
- د هر هېواد تعلیمي ادارې او رسمي سرچینې

## د ښوونځیو ملي لړلیکونه

د ښوونځیو معلومات له مستندو عامه یا اداري سرچینو څخه راځي. BRASA د معلوماتو سرچینه او د بیاکتنې نېټې ثبتوي، ورک ښوونځي نه جوړوي او د هر هېواد معلومات جلا نوي کوي.

## ژبنی لاسرسی

## زده کړه پیل کړئ
