# Ẹ̀kọ́ Brasa

**Gbogbo ilé-ẹ̀kọ́, gbogbo ìpele, gbogbo orílẹ̀-èdè tí ọmọ-ẹ̀kọ́ bá so pọ̀ láti orílẹ̀ èdè kan sí òmíràn.**

[Ṣí Ẹ̀kọ́ Brasa](https://brasa.education/)·[BRASA World](https://brasa.world/)·[Ìjọba](https://brasagovernment.net/)·[Okòwò](https://brasa.business/)

Ẹ̀kọ́ BRASA ń ran àwọn ọmọ ìlú lọ́wọ́ láti wá ilé-ẹ̀kọ́, ilé-ẹ̀kọ́ gíga, ẹ̀kọ́, ìwé-ẹ̀rí, àti àwọn ohun èlò ìkọ́nilẹ́kọ̀ọ́ lọ́fẹ̀ẹ́. Orílẹ̀-èdè kọ̀ọ̀kan gba ojú ìwé ẹ̀kọ́ tirẹ̀ àti ìwé ìtọ́sọ́nà ilé-ìwé, tí ó so mọ́ ojú ìwé Brasa pàtàkì orílẹ̀-èdè náà.

## Ohun tí àwọn ọmọ ìlú lè rí

- Ilé-ìwé àdáni àti ti gbogbo ènìyàn níbi tí àkóónú tí a ti fìdí múlẹ̀ ti wà.
- Awọn ile-ẹkọ giga ati ẹkọ imọ-ẹrọ
- Awọn ẹkọ ọfẹ ati awọn iwe-ẹri
- Awọn ọna ẹkọ fun awọn ọmọde ati awọn agbalagba
- Àwọn ilé ẹ̀kọ́ tí ó ṣe pàtó fún orílẹ̀-èdè àti àwọn ohun-èlò ìjọba

## Awọn Itọsọna Ile-iwe Orilẹ-ede

Àwọn àkọsílẹ̀ ilé-ẹ̀kọ́ wá láti orísun ìjọba tàbí ilé-ẹ̀kọ́ tí a kọ sílẹ̀. BRASA máa ń ṣàkọsílẹ̀ ibi tí ó ti wá àti àwọn ọjọ́ àtúnyẹ̀wò, ó máa ń yẹra fún àwárí àwọn ilé-ìwé tí ó sọnù, ó sì máa ń ṣe àtúnṣe àwọn àkójọ àkójọ àkójọ àkójọ àkójọ à

## Èdè ìfikúnsí

Èdè Gẹ̀ẹ́sì ṣì jẹ́ orísun tí ó wà. Àwọn ojúewé tó wà ní àdúgbò máa ń lo àwọn URL tó yàtọ̀, wọ́n sì máa ń ṣe àgbéyẹ̀wò wọn fún ọ̀rọ̀ ẹ̀kọ́, orúkọ ilé-ìwé, àwọn ìwé àfọwọ́kọ, ìtọ́sọ́nà, àti ìfikúnsí.

## BRASA lónìí

BRASA ti so àwọn ibi orílẹ̀-èdè 198 pọ̀ mọ́ Ẹ̀kọ́, Ìjọba àti Iṣòwò. BRASA Business ní apá 12 tí ó so pọ̀: títà àti risiti, CRM, ọjà inú ilé, ènìyàn àti ìdánilẹ́kọ̀ọ́, owó oṣù àti ilé-ifowopamọ́, àkókò, ìrànlọ́wọ́ ẹbí, iṣẹ́ òfin, fọ́ọ̀mù ìjọba, ìròyìn àti ibi iṣẹ́ àjọṣe. Ó tún ní ìwé ìṣirò ṣíṣi, ìlànà iṣẹ́ tí a darí àti ìtẹ̀síwájú láìsí íńtánẹ́ẹ̀tì.

BRASA Financials ṣe àkójọ àwọn ètò ìsanwó 385 láti inú àkọsílẹ̀ 395, pẹ̀lú àlàyé ọjà 161 àti irú ìsanwó 216: owó alágbèéká, gbigbe lẹ́sẹ̀kẹsẹ̀, QR, àpò owó díjítà, nẹ́tíwọ́ọ̀kì owó, fífi owó ránṣẹ́, open banking, káàdì abẹ́lé àti USSD.

Wíwà nínú àkójọ kò túmọ̀ sí pé a ti mú un ṣiṣẹ́. Àwọn olupèsè tó ní ìwé-àṣẹ ni wọ́n ń gbé owó; ọ̀nà kọ̀ọ̀kan nílò àyẹ̀wò orílẹ̀-èdè àti orísun, ìwé-àṣẹ, ìsopọ̀, ìdánwò ìsanpada àti ìfọwọ́sí iṣẹ́ gidi.
