# BRASA 教育

**每一所学校、每一个层级、每一位学习者，按国家逐一连接。**

[打开 BRASA 教育](https://brasa.education/) · [BRASA 世界](https://brasa.world/) · [政府服务](https://brasagovernment.net/) · [商业](https://brasa.business/)

BRASA 教育帮助公民查找学校、大学、课程、证书和免费学习资源。每个国家都有自己的教育页面和学校名录，并与该国的 BRASA 主页面相连。

## 公民可以查找的内容

- 在有核实数据的情况下提供公立和私立学校信息
- 大学和技术教育
- 免费课程和证书
- 面向儿童和成人的学习路径
- 各国教育机构和官方资源

## 国家学校名录

学校记录来自有据可查的公共或机构来源。BRASA 记录数据来源和审核日期，不虚构缺失的学校，并分别更新每个国家的数据集。

## 语言访问

英语仍是持续维护的源语言。本地化页面使用独立地址，并审核教育术语、学校名称、书写系统、文字方向和无障碍体验。

## 开始学习

访问 [brasa.education](https://brasa.education/)，或从 [BRASA 世界](https://brasa.world/) 上您所在国家的页面开始。

## 参与贡献

帮助查找官方学校数据来源、核实名录、审核翻译或报告过期的教育链接。

## 今天的BRASA

BRASA现已将198个国家目的地与教育、政府和商业连接起来。BRASA Business包含12个互联领域：销售与收据、CRM、库存、人员与培训、工资与银行、时间管理、家庭支持、法律事务、政府表格、报告以及共享工作空间。系统还包括开放账本、引导式工作流程和离线连续运行。

BRASA Financials已从395条记录中整理出385种支付系统，涵盖161个国家或多国市场描述以及216种支付类型，包括移动支付、即时转账、QR、电子钱包、现金网络、汇款、开放银行、本地卡系统和USSD。

被收录不代表已经启用。资金由持牌服务商转移；每种方式都必须经过国家与官方来源核验、许可审查、技术集成、结算测试和生产批准。BRASA把经过核验的选项连接到收据、对账和开放账本。
