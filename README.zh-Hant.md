# BRASA 教育

**每一所學校、每一個層級、每一位學習者，按國家逐一連結。**

[開啟 BRASA 教育](https://brasa.education/) · [BRASA 世界](https://brasa.world/) · [政府服務](https://brasagovernment.net/) · [商業](https://brasa.business/)

BRASA 教育協助公民尋找學校、大學、課程、證書和免費學習資源。每個國家都有自己的教育頁面和學校名錄，並與該國的 BRASA 主頁面相連。

## 公民可以尋找的內容

- 在有經核實資料的情況下提供公立和私立學校資訊
- 大學和技術教育
- 免費課程和證書
- 適合兒童和成人的學習路徑
- 各國教育機構和官方資源

## 國家學校名錄

學校記錄來自有據可查的公共或機構來源。BRASA 記錄資料來源和審查日期，不虛構缺少的學校，並分別更新每個國家的資料集。

## 語言存取

英語仍是持續維護的來源語言。在地化頁面使用獨立網址，並審查教育術語、學校名稱、書寫系統、文字方向和無障礙體驗。

## 開始學習

造訪 [brasa.education](https://brasa.education/)，或從 [BRASA 世界](https://brasa.world/) 上您所在國家的頁面開始。

## 參與貢獻

協助尋找官方學校資料來源、核實名錄、審查翻譯或回報過期的教育連結。

## 今天的BRASA

BRASA現已將198個國家目的地與教育、政府和商業連結起來。BRASA Business包含12個互聯領域：銷售與收據、CRM、庫存、人員與培訓、薪資與銀行、時間管理、家庭支援、法律事務、政府表格、報告以及共享工作空間。系統亦包括開放帳本、引導式工作流程和離線持續運作。

BRASA Financials已從395筆記錄中整理出385種支付系統，涵蓋161個國家或多國市場說明以及216種支付類型，包括流動支付、即時轉帳、QR、電子錢包、現金網絡、匯款、開放銀行、本地卡系統和USSD。

被收錄不代表已經啟用。資金由持牌服務商轉移；每種方式都必須經過國家與官方來源核驗、牌照審查、技術整合、結算測試和生產批准。BRASA把經過核驗的選項連接到收據、對帳和開放帳本。
