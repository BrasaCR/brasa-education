# BRASA Education

**Ар бир мектеп, ар бир деңгээл, ар бир окуучу — өлкөлөр менен байланышкан.**

[BRASA Education сайтын ачыңыз](https://brasa.education/) · [BRASA World](https://brasa.world/) · [Өкмөт](https://brasagovernment.net/) · [Бизнес](https://brasa.business/)

BRASA Education жарандарга мектептерди, университеттерди, курстарды, сертификаттарды жана акысыз окуу ресурстарын табууга жардам берет. Ар бир өлкө өзүнүн билим берүү барагын жана ошол өлкөнүн негизги BRASA барагына туташтырылган мектеп каталогун алат.

## Жарандар эмне таба алат

- Текшерилген маалыматтар бар мамлекеттик жана жеке мектептер
- Университеттер жана техникалык билим берүү
- Акысыз курстар жана сертификаттар
- Балдар жана чоңдор үчүн окуу жолдору
- Өлкөгө тиешелүү билим берүү мекемелери жана расмий ресурстар

## Өлкө мектептеринин маалымдамалары

Мектеп жазуулары документтештирилген коомдук же институттук булактардан келет. BRASA келип чыгышын жана карап чыгуу даталарын жазып, жетишпеген мектептерди ойлоп табуудан качат жана өлкөнүн маалымат топтомун өз алдынча жаңыртып турат.

## Тил мүмкүнчүлүгү

Англис тили сакталган булак бойдон калууда. Локалдаштырылган барактар ​​өзүнчө URL даректерин колдонушат жана билим берүү терминологиясы, мектеп аттары, скрипттери, багыты жана жеткиликтүүлүгү каралат.

## Үйрөнүүнү баштаңыз

[brasa.education](https://brasa.education/) сайтына кириңиз же [BRASA World](https://brasa.world/) сайтындагы өлкөңүздүн барагынан баштаңыз.
