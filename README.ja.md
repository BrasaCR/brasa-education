# BRASA 教育

**すべての学校、すべての教育段階、すべての学習者を国ごとにつなぎます。**

[BRASA 教育を開く](https://brasa.education/) · [BRASA 世界](https://brasa.world/) · [行政サービス](https://brasagovernment.net/) · [ビジネス](https://brasa.business/)

BRASA 教育は、市民が学校、大学、講座、修了証、無料学習資源を見つけることを支援します。各国には、その国の BRASA メインページにつながる専用教育ページと学校一覧があります。

## 市民が見つけられるもの

- 確認済みデータがある場合の公立・私立学校
- 大学と技術教育
- 無料講座と修了証
- 子どもと成人のための学習経路
- 国別の教育機関と公式資源

## 国別学校一覧

学校情報は、記録された公共または機関の情報源に基づきます。BRASA は出典と確認日を記録し、存在しない学校を作らず、各国のデータを個別に更新します。

## 言語での利用

英語は維持される原文です。ローカライズページは個別のアドレスを使い、教育用語、学校名、文字体系、文字方向、アクセシビリティを確認します。

## 学習を始める

[brasa.education](https://brasa.education/) を開くか、[BRASA 世界](https://brasa.world/) の国別ページから始めてください。

## 協力する

公式学校データの情報源の特定、一覧や翻訳の確認、古い教育リンクの報告にご協力ください。

## 現在のBRASA

BRASAは現在、198の国別ページを教育・政府・ビジネスと結び付けています。BRASA Businessには、販売時点管理と領収書、CRM、在庫、人材と研修、給与と銀行、時間管理、家族支援、法務、政府書式、レポート、共有ワークスペースという12の連携領域があります。オープン台帳、ガイド付きワークフロー、オフライン継続運用も含まれます。

BRASA Financialsは395件の記録から385の決済システムを整理し、161の国・複数国市場の説明と216の決済種類を収録しています。モバイルマネー、即時振込、QR、ウォレット、現金ネットワーク、送金、オープンバンキング、国内カード、USSDなどが含まれます。

掲載は利用開始や承認を意味しません。資金を移動するのは認可を受けた事業者です。各方式には、国と公式情報源の確認、認可、接続、決済テスト、本番承認が必要です。BRASAは確認済みの選択肢を領収書、照合、オープン台帳につなぎます。
